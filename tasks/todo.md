# NAMU 官网实施计划

## 成功标准

- 首页、Info、方太案例、FARFETCH China 案例均按 Figma 设计实现。
- 中文与英文拥有可分享、可被搜索引擎识别的独立 URL，并可互相切换。
- 支持跟随系统及手动切换亮色/暗色模式，刷新后保留选择。
- 375px 手机、768px 平板、1280px 及以上桌面均无横向溢出、文字裁切或交互遮挡。
- Logo、案例图、客户 Logo 等资源保存为站点本地文件，不依赖会过期的 Figma 临时链接。
- `make check` 通过，包含结构、资源、链接与构建产物检查。
- 服务器保留可回滚版本；Nginx 配置生效；`https://namu.design` 与 `https://www.namu.design` 可访问，HTTPS、跳转、缓存与 404 行为通过检查。
